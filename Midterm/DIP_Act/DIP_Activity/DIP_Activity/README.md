# DIP_Activity

Simple Windows Forms project for the "DIP Activity" midterm.

## Requirements
- .NET Framework 4.8
- Microsoft Visual Studio (e.g., Visual Studio Community 2026)

## Setup
1. Open the solution: `DIP_Activity.slnx` in Visual Studio.
2. Build the solution: **Build → Build Solution** (or press `Ctrl+Shift+B`).
3. Run the application: press `F5` or **Debug → Start Debugging**.

## Project layout
- `DIP_Activity/` — project files, including `DIP_Activity.csproj` and source code (e.g., `Form1.cs`).
